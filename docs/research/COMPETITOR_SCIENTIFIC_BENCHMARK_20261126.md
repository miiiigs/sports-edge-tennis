## Clean-room research hypotheses
1. Seed surface Elo with overall Elo vs neutral; predeclared low surface-history subgroup.
2. Add licensed lower-tier past results to state only; compare cold-start players, not ITF targets.
3. Test HistGradientBoosting vs A1/A2 originals on identical PIT rows, with recency form, opponent quality, fatigue and decayed H2H ablations.
4. Isotonic vs sigmoid calibration fitted only on earlier validation; no final test reuse. Compare daily vs weekly refits using observed result times.
5. Separate no-odds model, contemporaneous odds-assisted candidate and normalized two-sided bookmaker benchmark; identical issue cutoff, fixed prospective threshold, report accuracy/Brier/log loss and odds only where authorized. Freeze criteria before 30 days and 200 settled cases; no claim from selection bias or reconstructed history.

## Reproduction
Run `pytest -q tests/test_competitor_scientific_benchmark.py` in repository test environment. Tests are synthetic. Use ObservationStore with an absolute private SQLite path and an independently acquired permitted record plus frozen fixture and written grant manifest. Do not pass historical imports to receive(). Use score() with independent official settlements and frozen census; no deployment or scheduler included.

CLI: `python -m sports_edge_tennis.validation.competitor_scientific_benchmark pronocast-aggregate` recomputes the public band arithmetic without vendor data. `receive --db /private/receipts.db --record observation.json --fixture fixture.json --grant grant.json` and `score --db /private/receipts.db --fixtures census.json --settlements settlements.json --as-of ...Z` use operator-supplied local records only. TennisBrain terms https://www.tennisbrain.com/terms_of_service/ prohibit unauthorized reproduction and distribution. BananaPoint best-tip trust may refer to a non-winner market: never use it as winner probability or winner-confidence threshold.
