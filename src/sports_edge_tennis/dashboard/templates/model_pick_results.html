Model Picks Results

How often the model's selected player actually won.

Model Picks includes qualifying Manager picks and strong A1+A2 tracking picks that meet the current 60% rule. A Manager pick uses the Manager consensus probability. A wide-spread tracking pick is one where the Manager did not bet, A1 and A2 agreed on the same player, and their average confidence was still at least 60% — it is shown with its own label and is never counted as a Value Bet. One model pick is counted per sporting match, using the first qualifying evaluation. This ignores betting price and value.
