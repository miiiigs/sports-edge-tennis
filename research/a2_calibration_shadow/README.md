# Agent 2 probability-calibration shadow

Research-only experiment for the Agent 2 calibration assignment. Nothing in this
directory is imported by the production runner, dashboard, providers, Manager,
Market, Veto, staking or database code.

## Question

Can a strictly point-in-time probability calibration layer improve Agent 2's
historical probability quality without changing its selected winners, ranking or
raw prediction coverage?

## Pre-registered selection protocol

Candidates:

1. `identity`
2. `temperature` (one parameter: `sigmoid(b * logit(s))`)
3. `platt` (two parameters, constrained to keep `s >= 0.5`)
4. `isotonic_500`, `isotonic_200`, `isotonic_100`, `isotonic_50`
5. `piecewise_linear` on fixed 5-point edges

Selection uses only 2019-2021 predictions:

- Fit on 2019-2020, score 2021.
- Fit on 2019-2021, score 2022.
- Pool the 2021 and 2022 observations.
- Primary criterion: lowest pooled log loss.
- A candidate is tied with the best if its pooled log loss is within `0.0002`.
  Among tied candidates, choose the lowest complexity rank.
- The selected method must also improve pooled Brier and ECE over `identity`.
- Only after `selection.json` is written is the method refitted on 2019-2022 and
  evaluated on 2023-2025.

The test outcomes are never passed to the selection function. A regression test
flips every test outcome and asserts that selection is unchanged.

## Candidate definitions

All calibrators map the selected-side confidence `s` in `[0.5, 1]` to a
calibrated confidence in `[0.5, 1]` and are monotone non-decreasing. This has
three consequences:

- the selected player cannot change;
- directional accuracy and the raw prediction coverage cannot change;
- the ranking of matches by confidence is preserved.

`platt` is constrained to a non-negative intercept. `isotonic` uses
pool-adjacent-violators with a minimum block size. `piecewise_linear` pools
adjacent fixed bins and linearly interpolates between bin centres. The
`temperature` mapping extends symmetrically to player-1 probabilities via
`apply_symmetrically`.

## Metrics

- Brier score and log loss on selected-side probabilities.
- Expected calibration error over ten 5-point bins from 0.50 to 1.00.
- Reliability by 5-point bin and cumulative 0.60/0.70/0.80/0.90 bands.
- Cox calibration slope and intercept.
- Observed versus predicted at high confidence, including high-confidence losses.
- Paired match-level bootstrap 95% intervals (seed `20261021`).
- Threshold-crossing counts and the calibrated threshold that would preserve
  each baseline count.
- Coverage, abstention, selection-side changes and ranking inversions.
- Surface, tier, tour, season, history, inactivity and qualifying subgroups.

## Reproduce

```powershell
# 1. Selection only. This writes tmp/a2_calibration_shadow/selection.json
#    before any test evaluation exists.
python research/a2_calibration_shadow/harness.py `
  --records tmp/a2_form_lookback/records_baseline.jsonl `
  --output-dir tmp/a2_calibration_shadow `
  --artifacts-dir research/a2_calibration_shadow/artifacts `
  --frozen-dataset tmp/a2_frozen_20261019.jsonl `
  --mode select --reps 1000

# 2. Final test and artifacts. This reads the frozen selection.
python research/a2_calibration_shadow/harness.py `
  --records tmp/a2_form_lookback/records_baseline.jsonl `
  --output-dir tmp/a2_calibration_shadow `
  --artifacts-dir research/a2_calibration_shadow/artifacts `
  --frozen-dataset tmp/a2_frozen_20261019.jsonl `
  --mode test --reps 1000

# 3. Reliability chart.
python research/a2_calibration_shadow/plot_calibration.py

# 4. Focused tests.
python -m pytest tests/test_a2_calibration_shadow.py -q
```

`--mode all` runs both steps in one process. The two-step form is preferred
because it leaves an auditable `selection.json` that predates the test run.

## Safety

- No production model activation.
- No change to Agent 2, Manager, A1/A2 weighting, thresholds or betting logic.
- No production database mutation.
- No bookmaker prices and no ROI claim.
- Historical tournament-cohort replay results are kept separate from genuine
  forward-issued Model Picks.
