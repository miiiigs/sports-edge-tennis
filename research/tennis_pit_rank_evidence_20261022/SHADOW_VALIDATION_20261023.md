# Tennis ranked-cohort study and prospective shadow specification
Date: 2026-10-23. Owner: research lane. **Status: NOT YET EMPIRICALLY VALIDATED / NO LIVE RULE CHANGE.**

## Preregistered research question
H0: On unchanged first-production betting selection cohorts, suppressing matches when the **selected player has an independently verified pre-pick official singles rank 401–600** does not improve future out-of-sample accuracy after uncertainty and lost selections. H1: a consistent positive improvement might merit further prospective shadow testing; it is **not** permission to suppress picks or modify model rules. Opponent rank, absolute/signed rank gap, 1–100, 101–200, 201–400, 601+, unranked/unknown, surface, tour and tier are descriptive *secondary* analyses, not secretly optimized filters.

## Study population and essential controls
- Work from the immutable original finalized first-production matches: preserve model version, original timestamp, original direction/probability per Manager, A1 and A2, real production membership and canonical sporting ID. Keep official `MANAGER` and tracking-only `A1_A2_TRACKING` distinct. Never combine A1/A2 tracking rows with customer-facing issued Manager picks.
- Analyze three agents separately, using each agent's *original* selected side and probability; **orient selected-player rank, opponent rank and signed gap to that individual agent's selected side, not automatically the Manager's side**. Validate Manager-side canonical player identity against original side1/side2 IDs. Where a model does not have an original probability, exclude **only that model's score** and report denominator.
- Deduplicate by (population, canonical sporting match) using earliest eligible original selection; preserve later predictions solely as non-scored audit history. Do not cross-inflate identical matches across populations.
- Include only terminal COMPLETED selections with verified winner/loser for accuracy. Pending, VOID, retirement, winnerless walkover, cancellation or unresolved settlement do not enter the win/loss denominator until grading policy has independently reconciled them. Record their counts.
- Rankings are `OFFICIAL` only when ATP/WTA, exact player crosswalk, effective week, original publication at/before pick, complete coverage, SHA-256, and commercial rights are separately evidenced. Absence from a truncated feed is **UNKNOWN**, not officially unranked. For paired rank-gap analysis both ranks must be verified. Distinguish `ranking published on match week` from `ranking was available before original pick`.
- Stratify surface, tour, Challenger vs ATP/WTA vs ITF, qualifying/main, and preselected original confidence. No post-selection odds, newer Elo or later model version joins.
- Report accuracy (n / W / L), Wilson 95%, average original confidence, Brier, calibration gap, reliability bins/ECE, ranking availability and missingness per stratum. Use the same match/cohort denominator across baseline/filter comparisons and explicitly identify excluded losses and *lost winning selections*.

## Offline chronology and holdout
1. Freeze every raw input checksum, SQL query hash, source ranking archive/version, original selected population and exact extraction timestamp. Independent reviewer signs freeze before fitting any exclusions.
2. Preselect a calendar boundary **before looking at outcomes**. Use first 70–75% of available selections chronologically for exploratory cohort discovery and final 25–30% as a strictly later locked holdout; choose the actual cutoff based on available dates and record it before scoring. Prefer multiple contiguous month blocks and report all. Same match cannot cross partitions; embargo tournament-overlap windows and guard repeated player/event leakage. If observation period does not support independent calendar blocks, **holdout is not evaluable**.
3. The only primary tested hypothesis in the current pass is selected-player 401–600 suppression, predeclared above. Opponent ranks, gap bins and alternate filters must be explicitly labeled exploratory and require a **new** locked validation sample. Do not tune confidence thresholds.
4. Require >=40 scored historical train matches, >=20 train 401–600 exposures and >=20 retained train matches merely to evaluate a candidate; then >=40 scored holdout matches with >=20 exclusions and >=20 retained holdout matches. Higher power requirements may be mandated by independent quant review. For sparse strata, output `INSUFFICIENT`, not a victory.
5. `exclusion_holdout.py` implements a fixed timestamp boundary and deterministic, paired match-level bootstrap of held-out accuracy difference. Difference = retained accuracy minus unchanged baseline accuracy on the **same frozen population**, both using verified completed outcomes. It also reports held-out retention, lost winners and monthly/surface-tier stability. Wilson intervals for absolute accuracy remain in the pre-existing contract. It is intentionally **not** a causal uplift estimator; sample selection and correlated tournaments limit bootstrap validity.
6. Since six exploratory ranking bands, opponent ranks and gap/surface interactions amount to multiple comparisons, any promotion of secondary findings requires a recorded multiplicity adjustment (e.g., Holm correction over all tested variants) and an untouched later cohort. For the primary 401–600 hypothesis, require a two-sided interval excluding zero, exposure/retention adequacy, stability by month/surface/tour, calibration not harmed, and independent sign-off. Even a strong retrospective result is only **shadow candidate**, never automatic release.
7. Do not report ROI unless immutable original issued side, decimal price, offer timestamp <= pick, bookmaker, market, currency and stake/payout/grading definition are audited for the **entire compared exposure sample**. Guide Odds, post-pick prices and padded zero prices never qualify. This study currently reports **ROI unavailable**.

## Prospective shadow workflow
- At every production prediction, record (read-only) candidate membership, source ranking week, release-observed timestamp and verified canonical ID, player rank, opponent rank, official vs proxy, model version, confidence and reason for missingness.
- In parallel, compute `would_exclude_401_600` boolean in a separate **research-only store/export**. Never use it to gate live picks, publishing, confidence, staking or bookmaker decisions.
- Each UTC day reconcile original issued selections and final results; report retrospective baseline versus shadow-filtered outcomes, retention, excluded winners/losses, provider rank availability, and *pending/void* independently. Any missing or outdated rank sets `would_exclude_401_600 = false` but is marked UNKNOWN and reported; never silently count as outside band.
- Target a precommitted minimum of **8 consecutive weeks** and sufficient settled 401–600 exposure before review; evaluate separate tournament/surface and ATP/WTA subgroups. Extend if insufficient. Weekly league ranking release schedules have exceptions; do not infer release time from Monday midnight.
- At locked review, an independent quant/statistical reviewer signs cohort definition, attrition table, rank source rights/provenance, multiple comparisons, uncertainty, dataset checksum and event-level reproducibility. The release owner must independently authorize any future rule-change PR; this research PR **must never make such a change**.

## Hard stop criteria
Any of: no rights to historical source; ranking identity ambiguous; historical publication instant not evidenced; no immutable original production cohort; zero usable official PIT ranks; insufficient held-out exposures; conflicting winner settlement; unverifiable original decision prices for ROI; model version or canonical match mismatch.
